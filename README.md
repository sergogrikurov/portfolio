# Portfolio

Personal portfolio website built with Vue 3 + Vite.

## 🔧 Tech Stack

- Vue 3 (Composition API)
- Vite
- SCSS
- Vue Router
- Vue I18n

## 🌍 Features

- Multilanguage (EN / RU)
- Responsive design
- Mobile burger menu
- GitHub Pages deploy

## 🚀 Live Demo

https://sergogrikurov.github.io/portfolio

## 📦 Project setup

npm install

## 🛠 Development

npm run dev

## 🏗 Build

npm run build
